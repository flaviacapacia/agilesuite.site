# Transcenda Experience

Site estático do Movimento Transcenda, com páginas institucionais, Experience e contato.

## Páginas

- `index.html`: página inicial.
- `sobre.html`: história, vivências e apresentação da Cati.
- `landingpage.html`: página Transcenda Experience.
- `contato.html`: contato, parcerias e formulário via WhatsApp.
- `404.html`: página para endereços não encontrados.
- `sitemap.txt`: lista das páginas publicáveis.

## Publicação

Publique o conteúdo desta pasta mantendo a estrutura relativa, especialmente a pasta `img/` e o arquivo `style.css`. Configure o servidor ou a plataforma de hospedagem para usar `404.html` como página de erro 404.

O `sitemap.txt` usa caminhos relativos porque o domínio oficial não está definido neste projeto. Se a hospedagem exigir um sitemap no formato padrão, substitua cada caminho pelo domínio final, por exemplo:

```text
https://seu-dominio.com/index.html
```

Não altere os nomes dos arquivos sem atualizar os links da navegação e o sitemap.

## Identidade visual

O layout compartilha `style.css`, com tipografia Cormorant Garamond e Outfit, paleta clara em creme, pêssego e dourado, além de transições de entrada e efeitos de hover na página Experience.
